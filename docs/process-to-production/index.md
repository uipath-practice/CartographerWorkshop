# From Process to Production

!!! tip "Here is our plan for this exercise:"

    1. See how the PDD and SDD you just published travel on, from design to build, run and improvement.
    2. Review the **Solution Design Document (SDD)** you generated in **Cartographer** and sign it off.
    3. Set up **VS Code** with the **UiPath Maestro** extension and a coding agent.
    4. Have the coding agent build one of your **Maestro Flow** stages from the SDD, then validate it, deploy it to **Orchestrator** and open it in **Studio Web**.

## Goal

By the end of this exercise you'll have followed one design all the way down the line. One stage of the Cobalt Ridge SDD you generated in the first exercise becomes a working **Maestro Flow**, deployed to **Orchestrator** and open in **Studio Web** for your team. You'll also see how a change to the map finds its way back to the people, and the agents, who maintain the automation.
